NEW KFC STATIC WEBSITE

Extract the ZIP first. Upload index.html, styles.css, script.js, .nojekyll, and the assets folder together to the root of your GitHub Pages publishing folder. Keep the assets folder name and filenames unchanged.

The full stylesheet is embedded in index.html so styling does not depend on loading a separate CSS file. styles.css is included as an editable reference; if you change it, also update the matching style block in index.html.

You can also open index.html directly in a browser. Google Fonts is optional; system fonts are used when unavailable. Food images are included locally.

This is an independent concept, not an official KFC website.
